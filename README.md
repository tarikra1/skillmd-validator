# skillmd-validator

[![CI](https://github.com/tarikra1/skillmd-validator/actions/workflows/ci.yml/badge.svg)](https://github.com/tarikra1/skillmd-validator/actions/workflows/ci.yml)

**Linter, YAML frontmatter validator, relative link checker, portability scanner, and token-budget estimator for `SKILL.md` AI agent packages.**

## Quickstart

```bash
pip install -e .
skillmd-check ./my-skill/SKILL.md --max-tokens 4500
```
